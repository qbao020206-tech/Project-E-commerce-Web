## Các module được cài đặt trong dự án:

> **Flask:** 

* **Khái niệm:** Là một Web Framework siêu nhẹ (Micro-framework) viết bằng Python. Nhiệm vụ chính của nó là nhận các yêu cầu (HTTP Requests) từ phía người dùng (Frontend/Mobile), gọi đúng đoạn code Python để xử lý, và trả về kết quả (HTTP Responses).
* **Tư duy thiết kế (Tại sao lại dùng?):** Khi người dùng truy cập vào trang web hoặc app, dữ liệu truyền qua internet dưới dạng các gói tin HTTP thô. Nếu không có Flask, bạn sẽ phải tự viết code để "đọc" các gói tin này, tự tách URL, tự quản lý kết nối mạng... rất vất vả. Flask làm sẵn việc đó cho bạn một cách gọn gàng.
